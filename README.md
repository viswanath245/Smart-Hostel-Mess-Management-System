# Smart Hostel Mess Management System

## Project Description
A web-based application designed to simplify and manage hostel mess operations through a centralized platform.

## Technologies Used
- Frontend: React.js and Vite
- Backend: Node.js and Express.js
- Database: MySQL
- Database Connectivity: mysql2
- Authentication: JWT

## Main Modules
1. Student Portal
2. Staff Portal
3. Admin Portal
4. Meal and Menu Management
5. Meal Booking and Attendance
6. Feedback and Complaints
7. Rewards and Notifications
8. Inventory and Vendor Management
9. Crowd Monitoring and Food Waste Management

## Installation and Execution
1. Install Node.js and MySQL.
2. Import the database schema into MySQL.
3. Configure the backend environment variables using `.env.example`.
4. Run `npm install` inside the backend folder.
5. Start the backend using `npm start`.
6. Run `npm install` inside the frontend folder.
7. Start the frontend using `npm run dev`.

## Database
Database name: `smart_hostel_mess`

The database consists of 17 related tables.
